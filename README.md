## 🚀 Featured Projects

### 🛒 1. Smart Retail AI

**Technologies:** HTML, CSS, JavaScript, MySQL, LLM-based natural-language processing

An AI-powered mall shopping assistant that helps shoppers discover suitable stores based on their budget, category, and shopping requirements.

**Key Features**
- 🔎 Search for shops based on shopping requirements.
- 💰 Budget-aware shop ranking to find suitable options.
- 🏬 Display shop category, price range, floor, and shop number.
- 💬 Use an LLM-based natural-language interface to extract budget, category, and preferences from user queries.
- 🗄️ Retrieve relevant shop information from a MySQL database.

**Example:** A shopper can describe the products they need and their budget to find relevant shops inside the mall.

🔗 **Repository:** [Smart Retail AI](https://github.com/Nitin-G-A/Smart_Retail_AI-)
